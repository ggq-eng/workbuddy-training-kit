# workbuddy-training-kit

> **分类**：原创 / AI 打磨 ｜ **文件数**：14 ｜ **仓库目录**：`workbuddy-training-kit`

## 📌 简介

一套完整的 **WorkBuddy 零基础培训课程交付包**：面向「完全没用过 AI 办公工具」的
企业员工，4 周 × 半天 × 12 课时，从「敢用」走到「离不开」。

交付物分两层：

| 层 | 内容 | 给谁用 |
|---|---|---|
| **docs/** | 6 份可直接发放/授课的成品（方案、大纲、任务卡、题库、准备手册、交互面板） | 讲师、学员、培训组织方 |
| **scripts/** | 4 个 Python 生成脚本（`python-docx` + `openpyxl`），用于复刻或改写排版 | 需要改内容再重新出文档的人 |

## 🎯 适用场景

- 企业内部推行 WorkBuddy（或同类 AI 办公工具）需要一套**现成的培训物料**
- 培训讲师需要**页面级课件大纲**（照此做 PPT、照稿讲）
- 需要配套的**实操任务卡**与**考核评分体系**，让培训能验收而不是听完就散

## ✨ 功能特性

- **成品即交付**：6 份物料全部是排版完成的 .docx / .xlsx / .html，拿来即用
- **课程结构成型**：4 周 × 半天 = 12 课时，每周一个明确阶段目标
- **讲练比 4:6**：单课时 45 分钟拆成「导入 5 → 讲授 10 → 示范 10 → 实操 20 → 复盘 5」，
  保证 70% 时间在动手
- **有考核闭环**：30 题题库 + 3 套结业题组 + Rubric 评分表 + 成绩表，能组卷、评分、发证
- **有备课时间轴**：T-7 至 T-1 的准备清单与课中应急预案

## 📦 环境要求

| 项 | 要求 |
|---|---|
| 使用文档 | 无依赖（Office / WPS 打开 .docx / .xlsx，浏览器打开 .html） |
| 重新生成文档 | Python 3.9+，`pip install python-docx openpyxl` |
| 交互面板 | 浏览器打开 `docs/06_交互面板.html` 即可，无需服务端 |

## 🚀 快速开始

**作为讲师，直接取用：**

```bash
git clone https://github.com/ggq-eng/workbuddy-training-kit.git
cd workbuddy-training-kit/docs
```

然后按 `overview.md` 的课程结构走：每周一份大纲 + 一批任务卡，期末用题库组卷。

**想改内容再重新出文档：**

```bash
pip install python-docx openpyxl
python scripts/gen_main.py      # 总体方案
python scripts/gen_outline.py   # 课件逐页大纲
python scripts/gen_xlsx.py      # 任务卡 / 题库 / 准备手册
```

## 🧭 交付物详解

### `01_总体方案.docx`

给决策层与培训组织方看的完整方案：7 章 + 2 附录，35 张表格，
覆盖目标、对象、课程设计、考核、资源与风险。

### `02_课件逐页大纲.docx`

**页面级脚本**：K1-K12 共 77 页，每页都有该页要讲的内容与互动点。
讲师照此做 PPT、照稿讲，不用再自己组织语言。

### `03_实操任务卡.xlsx`

12 张任务卡 + 实操记录表。打印发放给学员，是「70% 时间在动手」的载体。

### `04_练习题库与考核评分表.xlsx`

- 30 题题库
- 3 套结业题组（可轮换，防背题）
- Rubric 评分标准
- 成绩表

### `05_素材清单与环境准备手册.xlsx`

工具清单、素材清单、检查表、**备课时间轴（T-7 至 T-1）**、课中风险预案。

### `06_交互面板.html`

课堂用交互面板，浏览器直接打开，无需服务端。

### `overview.md`

交付概览：交付物清单表、课程结构表、核心设计要点 —— **建议先读这份**。

## 📤 课程结构

| 周次 | 阶段 | 课时 | 阶段目标 |
|---|---|---:|---|
| W1 | M1 破冰与首次交付 | K1-K3 | **敢用**：当堂带走第一份 AI 交付文件 |
| W2 | M2 三大高频产出 | K4-K6 | **常用**：文档 / 表格 / PPT 三件套 |
| W3 | M3 指令质量与批量处理 | K7-K9 | **用好**：五段式指令 + 批量处理 |
| W4 | M4 自动化与结业 | K10-K12 | **离不开**：定时任务跑起来 + 通过考核 |

单课时 45 分钟：导入 5 → 讲授 10 → 示范 10 → 实操 20 → 复盘 5。

## 🔬 工作原理

```text
scripts/gen_main.py    ──▶ docs/01_总体方案.docx
scripts/gen_outline.py ──▶ docs/02_课件逐页大纲.docx
scripts/gen_xlsx.py    ──▶ docs/03/04/05 三份表格
scripts/docx_kit.py    ──▶ 上面三者共用的排版函数（字体/表格/页眉页脚）
```

**内容与排版分离**：脚本里是内容数据，`docx_kit.py` 负责套样式。
改内容只动脚本里的数据段，排版不会崩。

## ⚙️ 配置说明

| 项 | 说明 |
|---|---|
| 重新生成 | `pip install python-docx openpyxl` 后按上表跑脚本 |
| 改课程内容 | 编辑脚本里的内容数据段（标题/正文/表格数据），排版逻辑不用碰 |
| 换企业名 / 换工具名 | 在脚本里全局替换即可 |

> ⚠️ 生成脚本里有作者本机的输出路径（已统一为 `C:\Users\<你的用户名>\...` 占位），
> 使用前改成你自己的输出目录。

## ❓ 常见问题

**Q：不用于 WorkBuddy，能用于别的 AI 工具培训吗？**
课程结构（4 周四阶段、讲练比、考核闭环）是通用的，把具体工具操作那部分换掉即可。

**Q：12 课时要上完必须 4 周吗？**
推荐节奏是 4 周（每周留消化时间）。集中式 3 天也可以，但实操时间会被压缩，
「70% 动手」的设计初衷会打折扣。

**Q：生成的 docx 能直接改吗？**
能。脚本只是生成器，产物是普通 .docx/.xlsx，直接用 Office 改最方便；
只有要**批量调整格式**时才值得回头改脚本。

**Q：交互面板需要联网吗？**
不需要，纯本地 HTML。

## ⚠️ 注意事项

- `docs/` 下的成品与 `scripts/` 的生成逻辑是**对应关系**——直接改 docx 的话，
  下次重跑脚本会覆盖你的修改，二选一
- 课件大纲是「页面级脚本」，讲课时照稿讲即可，别临场发挥太多导致超时
- 考核 Rubric 建议结业前公开给学员，让他们知道评分标准
